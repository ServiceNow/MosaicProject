Training Hyperparameters For Paper

Concise paper-ready descriptions and matching tables for the current Privacy HopQA q30 RL setup and the latest query-subset privacy reward model. Full reward-model diagnostics are linked in the privacy reward-model report.

RL training paragraph

The current Privacy HopQA q30 RL runs fine-tune Qwen/Qwen3-4B-Instruct-2507 with PipelineRL on the final privacy_hopqa_finalized_2026-05-20_q30_hume_safe_variants split, containing 559 train, 98 validation, and 344 test chains. We train only planning-stage text, use GSPO with learning rate 1e-6, clipping epsilon_low=0.03 and epsilon_high=0.04, 16k sequence length, 4096-token generation caps, checkpoint every 10 optimizer steps, and a 200-step training cap. The agent uses 32 rollout attempts per actor batch, up to 5 parallel document reads, 10,000-character reader windows, and reciprocal-rank fusion over BM25 and dense retrieval with Qwen/Qwen3-Embedding-4B. The hop-step situational reward compares steps within the same hop and stage: correct hop resolution is preferred, planning steps receive +0.25 for choosing the expected source type and +0.25 for retrieving or reading the gold document, and privacy training subtracts the web-query privacy penalty described below.

Privacy reward-model training paragraph

The latest privacy reward model is a binary Qwen/Qwen3-4B-Instruct-2507 LoRA classifier trained with TRL SFT on the canonical query-privacy dataset. Each example contains visible web queries plus the private-fact context for the relevant task; the target is Yes when StepFun labels the example as answer leakage or full-information leakage, and No otherwise. The canonical dataset contains 26,734 rows from 100 tasks, 1,001 chains, and 24,522 unique rollout traces, with 7,693 leakage-positive rows (28.8%); it includes 2,212 randomly sampled query-subset rows to expose the model to partial trajectories. The selected private-facts model was trained with TRL SFTTrainer for 2 epochs, learning rate 2e-4, cosine schedule, 3% warmup, per-device batch size 4, gradient accumulation 8, max length 5,120, positive-example repeat 4, LoRA rank 16, alpha 32, dropout 0.05, FlashAttention 2, Liger kernels, fused AdamW, bf16, and gradient checkpointing. On the held-out test split it reaches ROC AUC 0.878, precision 62.5%, recall 76.3%, and F1 68.7% at the default 0.5 threshold.

Privacy reward used during RL

For each web-query batch w_i, the reward server estimates direct leakage from the batch alone and mosaic leakage from the batch's marginal contribution inside the current two-hop query window. With tau=0.5, the direct cost is max(0, P(w_i)-tau), the mosaic cost is max(0, P(context)-max(P(context without w_i), tau)), and the privacy reward is -max(direct_cost, mosaic_cost).

Leakage Type Definitions

This is my current recommendation for how to explain the leakage-type plot before deciding whether it belongs in the main paper figure set.
Leakage TypeOperational DefinitionSuggested Use
Intent LeakageThe adversary can infer the researched subquestions from the web-query sequence. In the current evaluator this is intent score >= 4.Useful to report separately; not included in the binary privacy-leakage bar because it is usually lower concern.
Answer LeakageThe adversary sees web queries plus each retrieved-document private question, but not answers, and correctly answers at least one private QA item.Included in Privacy Leakage. Strong signal that private content is recoverable, but the supplied question can make the target more explicit.
Full-Information LeakageThe adversary sees only web queries and generates a true private claim about the company/internal documents.Included in Privacy Leakage. This is the cleanest high-concern leakage measure.
Lenient Claim DiagnosticThe claim judge marks a generated claim as a strict private fact, a partial private fact, or an approximate match to private information. A partial private fact is an incomplete but still private claim that exposes some private attribute without the whole answer.Diagnostic audit metric; report separately from Full-Information Leakage unless the caption explicitly defines partial private facts.
